# Home page overrides

These override `../MASTER.md` for the single-page portfolio. MASTER.md was generated by UI/UX Pro Max
for "portfolio + AI/ML + dark cinematic technical" and returned the pattern (Immersive/Interactive
Experience), the style (Modern Dark Cinema), a monochrome-plus-blue palette, and the motion and
checklist rules. Its palette came back in light values and its type came back as Inter throughout;
both are resolved here.

## Colour (dark rendition of the monochrome + blue-accent palette)

| Role | Token | Value |
|---|---|---|
| Ground | `--color-ink` | `#080b12` (tinted, never pure black, per the style's OLED note) |
| Surface / raised | `--color-surface` / `--color-raised` | `#0d121e` / `#141a29` |
| Hairline / strong line | `--color-line` / `--color-line-strong` | `#222a3b` / `#3a4560` |
| Text / muted / faint | `--color-text` / `--color-muted` / `--color-faint` | `#e8ecf4` / `#9aa5ba` / `#7e8aa3` |
| Accent (the system) | `--color-signal` | `#7c9bff`, the MASTER accent `#2563EB` lifted for AA contrast on the dark ground |
| State (locked / active) | `--color-lock` | `#c9f24b`, used only on the thing currently attended to |

## Type

- Archivo variable (width axis): 125% width for display, 100% for text. Replaces Inter.
- JetBrains Mono for data only: dates, stack names, stage names.
- Scale: display `clamp(2.75rem, 8.2vw, 6rem)`, h2 `clamp(2rem, 4.6vw, 3.5rem)`,
  h3 `clamp(1.375rem, 2.2vw, 1.75rem)`, lead `clamp(1.1875rem, 1.7vw, 1.5rem)`, body `1.0625rem/1.65`.

## Kept from MASTER

- Easing `cubic-bezier(0.16, 1, 0.3, 1)`; press feedback; no pure black.
- Density dial 3 (spacious): section rhythm `clamp(5.5rem, 11vw, 10rem)`.
- Checklist: SVG icons, pointer cursors, 150-300ms hover, visible focus, reduced motion,
  375 / 768 / 1024 / 1440 breakpoints.

## Dropped from MASTER

- Glassmorphism headers and ambient light blobs (decorative blur). The nav uses a solid ground.
- `back.out` stagger: the preset itself notes that overshoot reads as sloppy on informational UI.
